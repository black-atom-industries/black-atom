# website

The Black Atom Industries site, a TanStack Start app that reads theme data from `@black-atom/core`.

- [`AGENTS.md`](AGENTS.md): file structure and the rules for changing it.
- [`docs/website.md`](../docs/website.md): what visitors see, and why.

Run `npm run dev` for the site, `npm run storybook` for the component catalog on port 6006, and
`npm run test:e2e` for the browser suite.
